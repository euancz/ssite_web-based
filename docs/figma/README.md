# Saved Figma Frame Notes

This folder contains one durable Markdown note per selected Figma frame. A note should capture the frame's structure, text, variables/tokens used, spacing, responsive hints, component hints, and manually exported assets.

Use a stable, readable filename based on the frame name, such as `page-home.md` or `workspace-president-dashboard.md`. Do not store tokens, passwords, private keys, or other credentials in these notes.

Before proposing a Figma read:

1. Check this folder for a matching note.
2. Read and reuse the note if it exists.
3. Refetch only when the user explicitly requests a refresh and approves the planned call.
4. Update the note immediately after an approved read.

If no MCP read is available, use [the fallback workflow](../FIGMA_NO_MCP_FALLBACK.md) and record the manually supplied frame information in the same format where practical.
