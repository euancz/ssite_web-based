# Figma MCP Call Log

This log records only Figma read calls made through this project's workflow. It cannot know about calls made in another repository, editor, account, or Figma client. At the start of each session, the agent must ask for the real monthly count before proposing a call.

The project default ceiling is **five read calls per calendar month**. The agent must show the planned single call and wait for written approval before using it. Exploratory calls are forbidden. Never refetch a frame that already has a saved note in `docs/figma/` unless the user explicitly asks for a refresh. If the ceiling is reached, use the no-call fallback and confirm the actual reset timing with the user; a calendar month is only the working assumption.
